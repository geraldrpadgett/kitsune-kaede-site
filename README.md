# Kaede Kitsune

Official website for **Kaede Kitsune** — a cozy creator with fox magic, games & art.

## Stack

This is a lightweight static site deployed on Cloudflare Workers Static Assets.

- Source: GitHub
- Hosting: Cloudflare Workers
- Production domain: https://kitsunekaede.com
- Deployment branch: `main`
- Continuous deployment: Cloudflare Git integration

## Local development

```bash
npm install
npm run dev
```

## Deploy

Cloudflare's Git integration deploys pushes to `main` automatically. Manual deployment is also available with:

```bash
npm run deploy
```
